# 💼 Portafolio Front End

Portafolio web desarrollado como parte del **Bootcamp de Desarrollo Front End**, con el objetivo de presentar mi perfil profesional, habilidades técnicas y proyectos desarrollados.

## 🚀 Tecnologías

- HTML5
- CSS3
- Bootstrap 5

## ✨ Características

- Diseño responsive.
- Interfaz moderna y limpia.
- Navegación intuitiva.
- Sección de presentación.
- Proyectos destacados.
- Información de contacto.

## 📁 Estructura del proyecto

```
📦 PruebaPortfolio
├── css/
├── img/
├── js/
├── index.html
└── README.md
```

## 💻 Cómo ejecutar el proyecto

1. Clona el repositorio:

```bash
git clone https://github.com/Emmeuve/PruebaPortfolio.git
```

2. Ingresa a la carpeta del proyecto:

```bash
cd PruebaPortfolio
```

3. Abre el archivo `index.html` en tu navegador o utiliza la extensión **Live Server** de Visual Studio Code.

## 🎯 Objetivos del proyecto

- Aplicar buenas prácticas de HTML semántico.
- Construir interfaces responsivas utilizando Bootstrap 5.
- Organizar correctamente la estructura de un proyecto Front End.
- Publicar el proyecto utilizando GitHub.
